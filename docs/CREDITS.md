# Créditos e insumos

## Mods y recursos

- **Carlos Leonhart**: archivo de opciones argentino Clausura 2012, base de planteles y uniformes. [Publicación](https://www.youtube.com/watch?v=cW4PuzhTcaQ).
- **Surling**: cánticos argentinos de 2012. [Publicación](https://foro.pesretro.net/thread-5869.html).
- **Lasso StaR Edition**: banco de relatos de Mariano Closs para PSP. [Publicación del autor](https://lassostareditions.blogspot.com/2026/04/nuevo-efootball-2026-v3-para-ppsspppsp.html). Los créditos adicionales del donante incluyen Chelito 19, Konami, Giiodroid y A. Gameplays Colombia.
- **Konami**: juego original. Este repositorio es un proyecto independiente y no está afiliado a Konami.

Los recursos de esos autores no se redistribuyen aquí. No se sintetizó la voz del relator.

## Herramientas externas

Los commits exactos figuran en `tools/dependencies.json`. El instalador obtiene el código de sus repositorios y conserva los avisos originales.

| Herramienta | Origen | Licencia observada en el checkout fijado |
| --- | --- | --- |
| PES/WE Option File Editor | [moth1995/PES_WE_11_14_OF_Editor](https://github.com/moth1995/PES_WE_11_14_OF_Editor) | MIT |
| pes-file-tools | [the4chancup/pes-file-tools](https://github.com/the4chancup/pes-file-tools) | Sin archivo de licencia en la raíz; consultar al proyecto para redistribución |
| atracdenc | [dcherednik/atracdenc](https://github.com/dcherednik/atracdenc) | LGPL 2.1; conservar los avisos de sus componentes |
| PSP savedata endecrypter | [cielavenir/psp-savedata-endecrypter](https://github.com/cielavenir/psp-savedata-endecrypter) | GPLv3+ según su README |
| pspdecrypt | [John-K/pspdecrypt](https://github.com/John-K/pspdecrypt) | GPLv3 |

FFmpeg, RetroArch y PPSSPP se utilizan como herramientas externas. Sus términos son independientes de los recursos del juego y los mods.
